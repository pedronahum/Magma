# Code of Conduct

Magma adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. In short: be respectful, inclusive and constructive,
and assume good faith.

It applies to all project spaces (issues, pull requests, discussions) and to
anyone representing the project elsewhere.

## Reporting

To report unacceptable behavior, contact the maintainer privately through
GitHub ([@pedronahum](https://github.com/pedronahum)). Reports are handled
confidentially. The enforcement guidelines in the Contributor Covenant apply.
